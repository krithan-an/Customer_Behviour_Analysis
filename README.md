# Data Analytics Project

## Overview

This project demonstrates a complete data analytics workflow using Python, PostgreSQL, and Power BI. The process includes loading the dataset, performing exploratory data analysis (EDA), cleaning and transforming the data, running SQL queries for business insights, and creating an interactive Power BI dashboard.

## Project Steps

### 1. Data Loading

* Imported the dataset using Pandas.
* Examined the dataset structure and data types.

### 2. Exploratory Data Analysis (EDA)

* Checked dataset summary statistics.
* Analyzed distributions and relationships between variables.
* Identified missing values and outliers.
* Created visualizations to understand trends and patterns.

### 3. Data Cleaning

* Removed duplicate records.
* Handled missing values.
* Corrected data types.
* Standardized column names and formats.

### 4. SQL Analysis

* Loaded the cleaned dataset into PostgreSQL.
* Wrote SQL queries to analyze:

  * Total revenue
  * Customer behavior
  * Product performance
  * Sales trends
  * Regional performance

### 5. Power BI Dashboard

Created an interactive dashboard featuring:

* KPI Cards
* Sales Overview
* Customer Insights
* Product Performance
* Trend Analysis
* Interactive Filters and Slicers
